production console The player's read of the live engine, embedded in the game client at a system you control (and reachable standalone at /console). Every figure is the engine's resolved value from the snapshot — the browser computes none (design.md §5); the two trend lines are the only client-side element, a rolling buffer of values the engine really sent. Tabs pick a tier, the row below a resource; goods with no local production/consumption show idle. The Syndicate tab lists this good's real producing ventures and the commitment the engine holds for each — 0 for all of them until the licence layer is built, so its thermometer reads no commitment yet. The top-up control and the hero's facility block are MOCK — design-ahead of an engine that does not have them; they are tagged on screen and send nothing.
